二、右键拖拽修复 — 原理对比
旧方案（闪烁根因）
pointerdown → 设200ms定时器 → 定时器到期才 isDraggingRef=true → 期间pointermove走第二分支检测移动>5px → 每次pointermove都调 desktopPet.moveWindow(deltaX, deltaY) → IPC到主进程 petWindow.setPosition() → 高频原生窗口移动 → DWM重绘冲突 → 闪烁
wheel在间隙期可能触发zoomBy → resizeWindow(setBounds)与moveWindow(setPosition)叠加 → 视觉放大效果
新方案（Live2D原理）
pointerdown → 立即 isDraggingRef=true + detachControl + setPointerCapture（无定时器间隙）
pointermove → 累计dragTotalDeltaX/Y + canvas.style.transform = translate(x,y)（GPU合成层，零IPC，零DWM重绘）
pointerup → 一次性 desktopPet.moveWindow(totalDeltaX, totalDeltaY) + canvas.style.transform = ''（窗口移动到目标位置，canvas回到正中）
wheel → isDraggingRef=true时立即return（无间隙期）
