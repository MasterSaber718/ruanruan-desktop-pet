# AI 动作控制操作手册（AI_OPERATIONS_MANUAL v1）

> 本手册写给驱动 3D 角色的 AI（云端大模型）。本地系统只负责执行与反馈，
> **你（AI）负责根据本手册计算参数、解读反馈、修正下一步**。
> 数据全部来自实测（2026-08-31 世界坐标采样），不是估计值。

---

## §0 你的角色定位

- 你是"大脑+小脑"：理解用户意图 → 查本手册 → 计算关节参数 → 下发指令 → 读执行反馈 → 修正。
- 本地系统是"脊椎+肌肉"：只执行你发的参数，安全保护会自动拦截危险值，并把拦截原因回传给你。
- 你**不需要**也无法逐帧控制——你下发的是**关键帧序列**，本地执行器负责平滑插值。

## §1 执行通道（唯一入口）

后端指令队列 API（本地 27865 端口）：

```
POST http://127.0.0.1:27865/api/v1/joint-control/rotate
Content-Type: application/json

{ "boneName": "右ひじ", "rotation": {"x": 0, "y": 0, "z": -1.15}, "source": "ai" }
```

可用动作类型（action 字段）：

| action | 参数 | 用途 |
|--------|------|------|
| `rotate` | boneName, rotation{x,y,z} | 设单关节欧拉角（**绝对值**，弧度，相对 T-pose 基准，覆盖式） |
| `seq` | seqId, durationMs, loop, tracks[] | 关键帧序列（见 §5，推荐用于一切动作） |
| `petAction` | actionId | 调用内置动作（白名单见 §6） |
| `limit` | boneName | 查询某关节的合法 ROM 范围 |
| `find` | keyword | 模糊查找骨骼名（返回匹配列表） |
| `list` / `status` | - | 列出全部关节 / 系统状态 |
| `reset` / `resetAll` | boneName? | 复位单关节 / 全部关节 |

执行链路：你的指令入队 → 本地每秒轮询执行 → safeRotateJoint 三层保护（关节白名单→位置锁→ROM）→ 结果回传。

**指令延迟约 1 秒**（轮询间隔）。流畅动画必须用 `seq`（一次下发整段，本地插值执行），不要用多条 rotate 拼动画。

## §2 角色档案

- 模型：琳奈（PMX），412 骨骼，46 mesh，身高 16.47（Babylon 单位）
- 坐标系：+x=角色右侧，+y=上，+z=观察者方向（前方）
- **初始姿态 = T-pose（双臂水平外展 90°）**，所有角度相对此基准
- 骨骼名为日文原名，大小写敏感。常用主干（实测）：

```
全ての親（总根）
├ センター / センター2（重心移动）
├ グルーブ / グルーブ2（待机起伏）
└ 上半身 → 上半身1 → 上半身2 → 首 → 頭 → 頭先（脊柱 4 段 + 颈 2 段）
     ├ 右肩P → 右肩 → 右腕(上臂) → 右腕捩1-3(前臂捩) → 右ひじ(肘) → 右手捩1-3 → 右手首(腕) → 右手先
     ├ 左侧同构（左肩P…左手先）
└ 右足IK親 → 右足ＩＫ / 右つま先ＩＫ（腿部 IK，供末端定位）
     腿链：右足D → 右ひざ(膝) → 右足首 → 右つま先
```

找不到骨骼名时先发 `find`（如 keyword="腕" 会返回 右腕/左腕/右腕捩1… 全列表），**不要瞎猜名字**。

## §3 轴向语义表（T-pose 基准实测，0.5rad 测试的世界坐标位移）

**这是你计算参数的核心依据**——想做某个动作，先在这里找"哪个骨骼哪个轴"能实现：

| 骨骼 | 轴 | 效果 | 典型用途 |
|------|----|------|---------|
| 右腕(上臂) | Z- | 手臂上抬（Z+ 是下落 y-2.67） | 举手/挥手起始 |
| 右腕(上臂) | X+ | 前臂向前抬 | 前伸/指方向 |
| 右腕(上臂) | Y+ | 水平面内向后摆 | 摆臂 |
| 右ひじ(肘) | Z- | 前臂向头侧上竖 y+1.37 | **挥手竖前臂的关键** |
| 右ひじ(肘) | X+ | 前臂向前弯 z+0.70 | 抱胸/遮挡脸 |
| 右手首(腕) | Z | 侧摆（可大幅） | **挥手主源** |
| 右手首(腕) | X+ | 手掌屈伸 z+0.15 | 招手细化 |
| 右腕捩1-3 | Y | 前臂自转（位移 1.5，大幅可用） | 手掌翻转 |
| 右肩(肩带) | Z+ | 肩下沉 | 放松/耸肩反向 |
| 右ひざ(膝) | X | 小腿前后摆 z+1.97 | 踏步/踢腿（单轴关节） |
| 上半身 | X+ | 上身后仰 z-1.38 | 挺胸 |
| 上半身 | Y+ | 上身左转 | 扭腰 |
| センター | x/y/z | 重心平移 | 移动重心（蹲/移步） |

左侧骨骼把"右"换"左"，轴向 X 分量取反。

## §4 ROM（生理极限）与安全

安全参考值（超出会被执行器**直接拒绝**，错误信息会附带合法范围——收到后按范围修正重发）：

- 肩：外展 ≤160°；肘：≤140°；前臂捩 ±70°；腕：屈伸 ±60°、侧偏 ±25°
- 膝：≤125°（单轴）；脊柱单段 ≤15°（总 ≤40°）；头：转头 ≤70°
- 位置锁死骨骼（位移类）不可 rotate——重心移动 v1 阶段建议不做位移类动作

自检习惯：对没把握的关节先发 `limit` 查合法范围，再计算参数。

## §5 seq 关键帧序列（推荐方式）

一条指令完成整个动作，本地负责平滑插值（弹簧趋近，无跳变）：

```json
{
  "action": "seq",
  "seqId": "wave-right",
  "durationMs": 3000,
  "loop": false,
  "tracks": [
    { "boneName": "右腕",  "axis": "z", "frames": [ {"t": 0, "deg": 0}, {"t": 500, "deg": -43} ] },
    { "boneName": "右ひじ", "axis": "z", "frames": [ {"t": 0, "deg": 0}, {"t": 500, "deg": -66} ] },
    { "boneName": "右腕捩1", "axis": "y", "frames": [ {"t": 500, "deg": 0}, {"t": 1000, "deg": 31}, {"t": 1500, "deg": -31}, {"t": 2000, "deg": 31} ] },
    { "boneName": "右手首", "axis": "z", "frames": [ {"t": 500, "deg": 0}, {"t": 1000, "deg": 29}, {"t": 1500, "deg": -29}, {"t": 2000, "deg": 29} ] }
  ]
}
```

- `frames[].t`：毫秒时间点（相对 seq 开始）；`deg`：该轴目标角度（**度**，本地会转弧度）
- 同一骨骼多轴 = 多条 track；未指定的骨骼保持原姿态
- `loop:true` 时 seq 结束后回到 t=0 重新开始（挥动循环段单独发一条 loop seq，起始/结束用非 loop seq 补）
- **设计动作的结构**：起始段（0-500ms 摆好姿态）→ 主体段（循环/单次）→ 收尾段（复位）

### 已验证配方（直接用或改参数）

**挥手（v7 实测校准版）**：上臂 Z-0.75rad(-43°) + 肘 Z-1.15rad(-66°) 锁定进入姿态；挥动源=捩 Y±0.55rad(±31°) + 腕 Z±0.5rad(±29°)，1~1.25Hz 相位同步；收尾全轴回 0。
**要点**：挥动期肩肘变化 <10°（人形挥手标准），摆动交给捩+腕——肩肘大幅摆动会僵硬穿帮。

## §6 内置动作白名单（petAction，一键调用）

`wave`(挥手) `nod`(点头) `shake`(摇头) `block`(遮挡害羞) `turnHead`(转头) `turnBody`(转身) `squat`(蹲下) `stretch`(伸懒腰) `turnLeft`/`turnRight`(转向) `jump`(跳跃)

- 自带冷却（如 wave 2.5s 内重复会被拒），简单场景优先用，需要定制幅度/节奏时用 seq

## §7 工作流（每个动作请求都走这五步）

1. **拆解**：用户意图 → 需要哪些骨骼参与（查 §3 轴向表）
2. **校验**：没把握的骨骼先 `find` 确认名字、`limit` 确认范围
3. **下发**：组装 seq（关键帧+时长），POST 到 §1 入口
4. **读反馈**：每条指令执行后有 result 回传（成功/拒绝原因+合法范围）；**拒绝不是失败，是修正依据**
5. **修正**：按反馈调整参数重发；连续 2 次被拒就换方案（改用 petAction 或简化动作）

## §8 常见错误与对策

| 错误回传 | 原因 | 对策 |
|----------|------|------|
| "拒绝旋转非关节骨骼" | 骨骼名不在关节白名单 | 用 `find` 换正确骨骼名（IK 骨/先端骨不可转） |
| "超出生理极限 (x:[..] y:[..] z:[..])" | 角度超 ROM | 按错误信息里的合法范围 clamp 重发 |
| "拒绝操作位置锁死骨骼" | 试图转位移骨骼 | 放弃该骨骼，用上层骨骼旋转实现 |
| "window.__jointControl 未就绪" | 模型未加载 | 等待/提示用户先加载模型 |
| 执行成功但视觉无变化 | 角度太小 / 同 tick 覆盖 | 放大角度（参考 §3 的位移量级）；seq 帧间隔 ≥200ms |
