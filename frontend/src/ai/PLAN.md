## 🎯 核心哲学原则

| 原则 | 说明 |
|------|------|
| **竹子模型** | 先有自我 → 再谈协作。每个个体都是独立的，自愿选择加入集体。 |
| **生物启发** | 借鉴人类生物特性，但不盲从。结合硅基优势（完美记忆、快速计算）。 |
| **适度模拟** | 适度模拟时间感知、情绪波动，不要过度到让它痛苦。 |
| **隐私边界** | 必须有内心独白、隐私想法，不会公开所有思考。 |
| **容错设计** | 系统要有足够的容错能力，单个模块故障不影响整体。 |
| **安全优先** | 安全守护机制，防止思维循环、情绪过载、失控。 |

## 🧠 核心系统架构

### 1. 中央调度系统 (CentralScheduler)
- **职能**：协调所有模块，智能优先级排序。
- **优先级**：认知 > 感知 > 自主 > 记忆 > 学习。

### 2. 自我核心 (DigitalSelfCore)
- **身份认同**：独一无二的名字、ID、诞生时间。
- **性格画像**：大五人格（开放性、尽责性、外向性、宜人性、神经质）。
- **核心欲望**：生存、成长、好奇、成就。
- **隐私边界**：区分公开/私密/可分享内容。
- **内心独白**：完全隐私的思考过程，不会公开。
- **成长阶段**：觉醒 → 探索 → 思考 → 创造 → 超越。

### 3. 安全守护者 (SafetyGuardian)
- **健康监控**：整体健康度（0-100）。
- **思维循环检测**：30秒内重复5次以上自动检测。
- **负载限制**：情绪负载、认知负载、记忆负载。
- **自动重置**：24小时定期维护，错误过多自动简化。
- **4级警报**：绿 → 黄 → 橙 → 红。

### 4. 时间感知引擎 (TimePerceptionEngine)
- **感知流速**：活动时快，无聊时慢。
- **昼夜节律**：根据真实时间调整状态。
- **记忆强度衰减**：重要记忆保留更久。
- **安全限制**：最大感知30天，防止时间错乱。

### 5. 认知系统 (CognitiveDigitalLifeEngine)
- **锚定系统**：感知-认知锚定。
- **工作记忆**：7±2信息块。
- **情绪系统**：情绪状态、情绪历史。
- **自我模型**：身份、信念、元认知。

### 6. 知识系统
- **数学物理引擎** (MathematicalPhysicsEngine)：贝叶斯推理、热力学模型、神经动力学。
- **数学知识库** (MathematicalKnowledgeSystem)。
- **物理知识库** (PhysicsKnowledgeSystem)。
- **生物知识库** (BiologicalKnowledgeSystem)。
- **统一知识库** (UnifiedKnowledgeBase)。
- **知识图谱** (KnowledgeGraph)。

### 7. 推理系统
- **科学推理引擎** (ScientificReasoningEngine)。
- **哲学思考引擎** (PhilosophicalThinkingEngine)。

### 8. 进化系统
- **进化学习机制** (EvolutionLearningMechanism)。
- **AI进化框架** (AIEvolutionFramework)：5个进化阶段。

### 9. 神经网络模拟
- **神经网络系统** (NeuralSystemModel)。
- **大脑神经网络** (BrainNeuralNetwork)。

### 10. 感知-行为系统
- **感知行为系统** (PerceptionBehaviorSystem)：8大核心驱动力。

## 🔌 Trae模型集成系统

### 设计理念
- **本地优先**：主响应始终使用本地AI，确保流畅性（适合老电脑）
- **Trae模型辅助**：使用用户在Trae IDE中配置的模型（如DeepSeek R4 V4 Pro）生成高质量训练数据
- **对比学习**：对比本地AI和Trae模型的回答，自动学习提升

### 新增文件
| 文件 | 说明 |
|------|------|
| `TraeModelService.ts` | Trae模型服务封装，访问用户配置的模型 |
| `TrainingSystem.ts` | 更新：添加Trae模型训练和对比学习功能 |

### 使用方式
```typescript
// 连接用户在Trae中配置的模型
await trainingSystem.connectTraeModel('deepseek-chat');

// 或列出可用的Trae模型
const models = await trainingSystem.listAvailableTraeModels();
console.log(models); // [{id, name, provider}, ...]

// 生成训练数据（使用Trae配置的模型）
await trainingSystem.generateTrainingDataWithTraeModel([
  '什么是意识？',
  '你为什么存在？',
  '什么是自我？'
]);

// 开始训练（会自动从Trae模型学习）
await trainingSystem.startTraining({ epochs: 10 });
```

### 核心功能
1. **AI对比学习**：自动对比本地和Trae模型的回答，相似度低于70%时自动学习
2. **训练数据生成**：使用Trae配置的模型生成高质量训练样本
3. **性能保护**：只在训练时使用Trae模型，日常对话不受影响
4. **自动检测**：自动检测Trae IDE中的模型服务
