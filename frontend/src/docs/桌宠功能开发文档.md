## 一、功能概述

桌宠功能让3D角色以**透明无边框窗口**形式显示在Windows桌面上，类似Live2D桌面宠物。角色可以旋转、缩放，透明区域鼠标穿透到桌面。

### 架构设计

```
主窗口 (NewPage.tsx)                    桌宠窗口 (PetPage.tsx)
┌─────────────────┐                    ┌─────────────────────┐
│ 导入PMX模型     │──IPC(show)──→     │ Electron透明窗口     │
│ BabylonModelViewer│                  │ frame:false          │
│ desktopPetMode=false│                │ transparent:true     │
└─────────────────┘                    │ BabylonModelViewer   │
                                       │ desktopPetMode=true  │
                                       └─────────────────────┘
                                               ↕ fetch
                                       ┌─────────────────────┐
                                       │ 5175静态服务/pet-tmp/│
                                       │ 模型+贴图临时文件    │
                                       └─────────────────────┘
```

**关键设计决策**：
- 桌宠是**独立Electron窗口**（非主窗口内嵌），加载 `/pet` 路由
- 模型数据通过**文件中转**传输（非IPC ArrayBuffer），绕过 sandbox 限制
- 桌宠窗口用**独立入口**（index.tsx），绕过 App/CssBaseline 白底污染

## 三、修改记录（2026-08-06 会话）

### v9：相机正面+全身显示 ✅
**问题**：alpha=π/2显示背面；桌宠只显示上半身  
**根因**：模型面向-Z方向，alpha=π/2相机在+Z看到背面；预览版参数复用到桌宠  
**修复**：
- `alpha = -Math.PI / 2`（相机在-Z方向，看到面向-Z的模型正面）
- 桌宠模式：`targetY = modelHeight * 0.5`（模型中心），`visibleHeight = modelHeight * 1.1`（全身）
- 预览模式：`targetY = modelHeight * 0.85`（脸部），`visibleHeight = modelHeight * 0.35`（上半身）
- **文件**: BabylonModelViewer.tsx L3933-3959

### v8：鼠标交互+相机角度 ✅
**问题**：无法缩放/旋转；角色侧对着  
**根因1**：ray pick只检测rootMesh（`m === mesh`），但PMX的rootMesh是`__root__`容器节点**没有几何体**，ray pick永远不命中→鼠标永远穿透→相机收不到事件  
**根因2**：alpha=0时相机在+X方向（Babylon.js公式：alpha=0→+X），不是+Z  
**修复**：
- ray pick去掉过滤函数：`scene.pick(x, y)` 检测所有mesh
- 退出按钮`onMouseEnter`调用`setIgnoreMouse(false)`
- **文件**: BabylonModelViewer.tsx L1881-1885, L4082

### v7：React设计缺陷修复（最关键） ✅
**问题**：模型加载成功后立即消失，像素诊断meshCount=0  
**根因**：PetPage的`onClose`是内联箭头函数，每次渲染新引用→BabylonModelViewer场景初始化useEffect依赖`[onClose]`→onClose变化触发useEffect清理→**dispose旧场景(46个mesh)→创建新空场景**  
**第二重缺陷**：getModel()和model-updated事件同时为同一模型创建不同modelData引用→模型加载useEffect重新触发  
**修复**：
1. PetPage: `onClose`用`useCallback`包裹（handleClose，空依赖）
2. BabylonModelViewer: 场景useEffect依赖从`[onClose]`改为`[]`，onClose用ref存储
3. PetPage: `loadedUrlRef`记录已加载URL，相同URL跳过setModelData
- **文件**: PetPage.tsx L126-131/L255-257, BabylonModelViewer.tsx L1577/L2089-2092

### v6：WebGL1+像素诊断 ✅
**问题**：GL_INVALID_VALUE着色器错误，截图2414字节纯透明  
**根因**：alpha:true + WebGL2 + 该系统GPU驱动 = 着色器编译失败  
**修复**：
- 桌宠模式强制WebGL1：`disableWebGL2Support: true`
- 添加像素级诊断：`executeJavaScript` + `gl.readPixels` 读取帧缓冲
- 添加渲染队列诊断：mesh数量/可见性/包围盒/视锥体
- **文件**: BabylonModelViewer.tsx L1668, electron-main.js capturePetWindowDiag

### v5：后处理管线+premultipliedAlpha ✅
**问题**：模型加载成功但渲染结果纯透明  
**根因1**：`premultipliedAlpha: false` 导致MMD材质合成错误  
**根因2**：DefaultRenderingPipeline在alpha:true时RTT合成丢失模型  
**修复**：
- 移除`premultipliedAlpha: false`（恢复默认true）
- 桌宠模式跳过DefaultRenderingPipeline
- **文件**: BabylonModelViewer.tsx L1660-1668, L1779-1796

### v4：客观验证+诊断模式 ✅
**问题**：无法确认窗口是否真的显示  
**修复**：
- show()后验证isVisible（不再主观假设"已显示"）
- capturePage截图诊断（文件大小判断：<1KB空, 1-10KB纯色, >50KB有模型）
- 屏幕信息日志（多显示器/DPI/工作区）
- 诊断模式：`.pet-debug`文件→非透明品红窗口+边框
- **文件**: electron-main.js createPetWindow/capturePetWindowDiag

### v3：文件中转方案 ✅
**问题**：IPC传输ArrayBuffer在sandbox+contextBridge下丢失  
**修复**：
- 主进程把模型/贴图写入`userData/pet-tmp/`
- 5175静态服务`/pet-tmp/`路由暴露URL
- 桌宠窗口用fetch获取ArrayBuffer
- 退出时清理临时目录
- **文件**: electron-main.js PET_TMP_DIR/cleanPetTmpDir, PetPage.tsx fetchTextureBuffers

### v2：透明窗口修复 ✅
**问题**：窗口纯白不透明  
**根因**：resizable:true + DevTools打开 + disableHardwareAcceleration  
**修复**：
- `resizable: false`（Electron官方：透明窗口不可调整大小）
- 禁止打开DevTools（DevTools打开时窗口不透明）
- 移除`app.disableHardwareAcceleration()`（新版Electron中失效且破坏透明）
- **文件**: electron-main.js createPetWindow

## 四、核心技术要点

### 4.1 Electron透明窗口配置（必须严格遵守）
```javascript
petWindow = new BrowserWindow({
  transparent: true,           // 透明
  frame: false,                // 无边框
  backgroundColor: '#00000000',// 透明背景
  resizable: false,            // 【关键】必须false，否则透明失效
  hasShadow: false,
  alwaysOnTop: true,
  skipTaskbar: true,
  show: false,                 // 等ready-to-show
  webPreferences: {
    contextIsolation: true,
    sandbox: true,
    preload: path.join(__dirname, 'preload.js'),
    // 不得打开DevTools（破坏透明）
  }
});
```

### 4.2 Babylon.js Engine配置（桌宠模式）
```typescript
const engineOptions: any = {
  preserveDrawingBuffer: true,
  stencil: true,
  disableWebGL2Support: true,  // 【关键】强制WebGL1，避开WebGL2+alpha着色器bug
  alpha: true,                  // 【关键】启用alpha通道，让canvas透明
  // 不设置 premultipliedAlpha（用默认true，MMD材质需要）
};
// 桌宠模式跳过 DefaultRenderingPipeline（与alpha:true冲突）
```

### 4.3 鼠标穿透策略
```
默认: setIgnoreMouseEvents(true, {forward:true})  ← 透明区域穿透到桌面
鼠标移动到模型上: ray pick命中 → setIgnoreMouse(false) ← 接收点击/滚轮
鼠标离开模型: ray pick不命中 → setIgnoreMouse(true)  ← 恢复穿透
退出按钮: onMouseEnter → setIgnoreMouse(false) ← 按钮始终可点击
```

### 4.4 React防场景重建（最易踩坑）
```typescript
// ❌ 错误：onClose内联函数，每次渲染新引用
<BabylonModelViewer onClose={() => hide()} />

// ✅ 正确：useCallback保持引用稳定
const handleClose = useCallback(() => hide(), []);
<BabylonModelViewer onClose={handleClose} />

// ✅ 场景初始化useEffect依赖必须为空数组
useEffect(() => { /* 创建Engine/Scene */ }, []);  // 不是 [onClose]！
```

## 六、已知问题和待办

### 待验证
- [ ] v9相机正面+全身显示是否正确（alpha=-π/2）
- [ ] 鼠标在角色上时旋转/缩放是否正常
- [ ] 透明区域鼠标穿透是否正常

### 已知限制
1. **WebGL1限制**：桌宠模式强制WebGL1，某些Babylon.js高级特性不可用（实例化渲染等）
2. **后处理缺失**：桌宠模式跳过DefaultRenderingPipeline，无FXAA抗锯齿（靠Engine antialias:true）
3. **GL_INVALID_VALUE警告**：WebGL1下仍有着色器警告（非致命，不影响渲染）
4. **模型朝向假设**：当前假设模型面向-Z方向，不同模型可能需要调整alpha

### 优化建议
1. 相机角度可根据模型包围盒自动判断朝向（比较X/Z轴尺寸）
2. 添加桌宠窗口拖拽功能（当前窗口位置固定）
3. 添加桌宠窗口缩放限制（clampZoomToBounds已实现，需验证）
4. 考虑添加右键菜单（切换模型/退出/设置）
