# 琳奈（412 骨骼）运动学知识库
> 实测来源：CDP 世界坐标采样（2026-08-31）。坐标系：+x=角色右侧，+y=上，+z=观察者方向（前）。
> 模型初始姿态 = T-pose（双臂水平外展 90°），所有动作角度均相对此基准。

## 〇、帧分支符号基准（2026-09-08 定案——写动作代码前必读）

> 背景：jump 膝反弯事故（2026-09-08 用户肉眼实锤）暴露「AI 分不清前后左右」——本节是方向约定的唯一权威，所有帧分支（BabylonModelViewer action 分支）必须遵守。

**朝向（世界坐标）**：
- 模型面向 **+Z**（正面朝相机/观察者）；+X = 角色自身右侧；+Y = 上
- 「前屈/前抬/低头」= 肢体前端向 +Z 摆；「后摆/后仰」= 向 −Z 摆

**旋转符号（局部欧拉 offset，乘在 rest 四元数上）**：
| 规则 | 符号 | 依据 |
|---|---|---|
| 全身默认：X+ = 前屈方向 | 頭/首 X+=低头；上臂 X+=前抬；肘 X+=前弯；大腿 X+=前抬 | CDP 实测（本表二节）+ 已验证家族 |
| **例外：膝（ひざ）是铰链，只能 X−**（小腿后折） | 膝 X+ = 反弯（小腿前踢=解剖不可能），**禁用** | 2026-09-08 jump 膝反弯事故实锤 + CDP（膝 X+→踝 z+1.97 向前） |
| 踝背屈 = X+（下蹲勾脚） | squat +0.5 / jump +0.35 一致 | 代码一致家族 |
| Z 外展：左臂 +Z / 右臂 −Z（镜像同动按 detectSide 取符号） | | wave/cheer 已验证 |
| 上半身 X 符号 ⚠️ 待肉眼验 | CDP 实测：上半身 X+ → z−1.38（后仰）；但 stretch 用 X−0.4=后仰、jump 用 X+0.2=前倾，**两处与 CDP 矛盾** | 肉眼验收时一并定案 |

**骨名事实（PMX 日文原名，关键词匹配必须覆盖）**：
- 大腿骨 = **足 / 足D**（左足/右足）——不是「もも」「大腿」！关键词列表必须含「足」
- 小腿旋转骨 = ひざ / ひざD；踝 = 足首 / 足首D；脚尖 = つま先
- **分支顺序铁律**：`ひざ → 足首 → 足`（「足」是「足首」的子串，足首先判，否则误吞）
- 2026-09-08 实锤：squat/bounce/stomp/approach 的大腿分支关键词（もも/大腿/thigh）匹配不到「足」，髋屈静默失效多时，已修复

**验证方法**（铁律第 3 条的落地）：肉眼侧视 + 子骨骼世界坐标 delta 采样；符号存疑时用 CDP 采样 0.5rad 单轴测试，勿靠猜。

## 三、生理活动范围（ROM，动画安全值）

肩：三轴，外展≤160°；肘：单轴 X ≤140°；前臂捩：±70°；腕：屈伸±60°、侧偏±25°；膝：单轴≤125°；脊柱：单段≤15°总≤40°；头：转头≤70°

人形挥手标准（文献+实测）：肩外展95°锁定、肘弯89°锁定，挥动期肩肘变化<10°；摆动源=前臂旋±30°+腕侧摆±30°，1-1.25Hz。
琳奈 T-pose 换算：上臂 Z-0.75 + 肘 Z-1.15 + 捩 Y±0.55 + 腕 Z±0.5

## 四、驱动铁律（违反=无效）

1. 只在 visible 页面驱动（hidden 页 rAF 暂停）
2. bone.setRotationQuaternion(q, 0) 必须带 Space.LOCAL=0
3. 验证只认 getWorldMatrix().getTranslation() 采样 delta（RQ 属性是假指标）
4. set 与读数必须跨渲染帧（同 tick 内 delta=0，set 后 sleep ≥150ms 再读）

## 五、动作与触发

- wave：肩 Z-0.75 + 肘 Z-1.15 锁定 + 捩 Y±0.55 + 腕 Z±0.5，1Hz 循环 600s
- 触发：POST http://127.0.0.1:9877/api/motion/request {mode:param, action:wave, params:{duration,amplitude,freq}}
- 链路：hub(9877) → 桌宠桥(280ms 轮询) → __petAction → PetActionExecutor → 动作系统
