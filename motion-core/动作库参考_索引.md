## 渲染端接入
- 播放器：`frontend/src/motion/vmdClipPlayer.ts`
- 资产目录：`frontend/public/vmd/`（构建后 → `frontend-dist/vmd/`）
- 触发：`POST /api/v1/joint-control/pet-action {"actionId":"vmdClip","params":{"asset":"idle_刘TWT.motion.json"},"source":"user"}`
- 或控制台：`window.__petAction('vmdClip', { asset: 'idle_刘TWT.motion.json' })`

## 使用原则（给 AI / 后续开发）
1. **不要凭空发明角度**——没有把握时查本索引，选库内原地动作作参考。
2. 库数据 = 真人/作者手调关键帧，自然度上限远高于程序化 sin 摆。
3. 空间位移类动作仅预览模式用；三线（桌宠/壁纸/预览）优先原地类。
4. 新动作：先入库解析 → pipeline 转 motion.json → 人眼确认 → 再进配方。
